## Visual Hierarchy & Anchors

- **Primary Visual Anchor / Focal Point**: Top KPI Summary Ribbon (hero metric: Daily Focus Time with violet glow border) followed by the Daily Focus Duration Bar Chart.
- **Visual Hierarchy Levels**:
  - Level 1: Top KPI Summary Ribbon & Hero Stat Cards (Total Focus Time, Current Streak, Productivity Score, Completed Tasks)
  - Level 2: Daily Focus Duration Bar Chart (primary activity trend canvas)
  - Level 3: Project Workload Donut Chart & Task Completion Velocity Area Chart (secondary distribution analytics)
  - Level 4: Segmented timeframe controls, axis captions, and metadata badges
- **Icon Action Accessibility**: Refresh button provides an accessible tooltip and aria-label "Refresh Analytics Data".

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Refresh Analytics Data |
| Secondary CTA | Change Timeframe |
| Empty state heading | No Focus Sessions Recorded |
| Empty state body | Start a focus timer or complete a mission task to populate productivity metrics, velocity trends, and project workload breakdowns. |
| Error state | Unable to query local SQLite analytics repository. Check file storage permissions and click 'Refresh Analytics Data' to retry. |
| Destructive confirmation | None: Phase 1 is a read-only analytics dashboard with no destructive actions. |

## UI Considerations

Applicable state considerations resolved: 5 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| Empty State | Analytics Dashboard Canvas | ✅ covered | When SQLite returns 0 sessions and tasks for the active period, render empty state card with heading "No Focus Sessions Recorded" and descriptive guidance. |
| Loading State | KPI Cards & Chart Canvases | ✅ covered | Display animated Skeleton pulse components conforming to exact card dimensions while async TanStack Query evaluates. |
| Error State | Analytics Query Service | ✅ covered | Render alert banner with specific SQLite error message and actionable "Refresh Analytics Data" retry CTA. |
| Populated State | KPI Ribbon & Recharts | ✅ covered | Render 4-card KPI ribbon, Daily Focus bar chart, Project workload donut, and Task velocity area chart with smooth re-render transitions. |
| Partial / Filter State | Timeframe Segmented Control | ✅ covered | Switching between Today, Last 7 Days, Last 30 Days, All Time updates query parameters and renders cached/fresh aggregated datasets seamlessly. |
| Long-Text / Truncation | Project Legend Labels | 🧪 backstop | Long project titles in the workload donut legend are clamped with ellipsis and display full title via accessible Hover Tooltip. |
