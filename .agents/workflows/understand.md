# Workflow: understand

Follow the `understand` skill to analyze the Akira codebase and build or update the knowledge graph in `.ua/`.

### Steps:
1. Run `/understand` to scan and analyze the repository.
2. Run `/understand-dashboard` to view the interactive graph in your browser.
3. Use `/understand-chat` or `/understand-explain` for targeted architectural queries.
