# Plan 01-01: Server RPC, Query Hook, Date Range Filter Expansion, Tool Registry Activation

## Overview

Plan 01-01 establishes the foundational data access and real-time infrastructure for the Dynamic Analytics Dashboard. It bridges the existing SQLite calculation engine (`src/analytics/`) to the browser runtime via a TanStack Start Server Function (`createServerFn`), adds full support for the `"allTime"` timeframe query filter, introduces an event-reactive client hook (`useDashboardQuery`) backed by `@tanstack/react-query` and `globalEventBus`, and activates the Analytics tool inside the desktop workspace tool registry.

   - Export `getDashboardDataRpc`:
     ```typescript
     export const getDashboardDataRpc = createServerFn({ method: "GET" })
       .validator((opts?: AnalyticsQueryOptions) => opts)
       .handler(async ({ data: opts }): Promise<DashboardDTO> => {
         const start = performance.now();
         const { dashboardService } = await import("../dashboard-service");
         const result = dashboardService.getDashboard(opts);
         const duration = performance.now() - start;
         console.log(`[Observability] Analytics dashboard compiled in ${duration.toFixed(2)}ms`);

       });
     ```

   - Import `useEffect` from `"react"`.
   - Import `useQuery`, `useQueryClient` from `"@tanstack/react-query"`.
   - Import `globalEventBus` from `"@/instrumentation/event-bus"`.
   - Import `Events` from `"@/contracts/events"`.
   - Import type `AkiraEvent` from `"@/instrumentation/event-types"`.
   - Import `dashboardClientService` from `"@/analytics/dashboard/services"`.
   - Import type `PredefinedDateRange` from `"@/analytics/service/filters"`.
   - Import type `DashboardDTO` from `"@/analytics/dashboard/dashboard-dto"`.
   - Export hook `useDashboardQuery(range: PredefinedDateRange = "last7Days")`:
     - Access `queryClient = useQueryClient()`.
     - Use `useQuery({ queryKey: ["analytics-dashboard", range], queryFn: async ({ signal }) => dashboardClientService.getDashboard({ range, filters: { timezone: -new Date().getTimezoneOffset() } }, signal), staleTime: 60_000, refetchOnWindowFocus: false })`.
     - Setup reactive `useEffect`:
       - Define subscriber object:
         ```typescript
         const subscriber = {
           id: "analytics-dashboard-reactive-sync",
           onEvent: (event: AkiraEvent) => {
             const isSessionEvent =
               event.type === Events.SESSION_ENDED ||
               event.type === "session.completed" ||
               event.type === "session.stopped";
             const isTaskEvent =
               event.type === Events.TASK_UPDATED ||
               event.type === Events.TASK_COMPLETED;
             if (isSessionEvent || isTaskEvent) {
               queryClient.invalidateQueries({ queryKey: ["analytics-dashboard"] });
             }
           },
         };
         ```
       - Call `globalEventBus.subscribe(subscriber);`.
       - In cleanup return, call `globalEventBus.unsubscribe(subscriber);`.
       - Add `[queryClient]` as dependency array.
     - Return `{ data, isLoading, isError, error, refetch, isFetching }`.
2. Create `src/components/analytics/useDashboardQuery.test.ts`:

     c) Emitting `Events.TASK_UPDATED` calls `queryClient.invalidateQueries`.
     d) Emitting unrelated events does not trigger invalidation.
     e) Unsubscribing removes subscriber from `globalEventBus` during cleanup.
