# Plan 01-02: Visual Dashboard Widgets, Recharts Visualizations, Route Integration

## Overview

Plan 01-02 delivers the visual presentation layer and user-facing route at `/tools/analytics`. It implements the 4-part dashboard layout specified in `01-CONTEXT.md` and `01-UI-SPEC.md`: (1) Top KPI Summary Ribbon with hero violet glowing Total Focus Time card, streak continuity, productivity score, and completed task count; (2) Daily Focus Duration Bar Chart; (3) Project Workload Distribution Donut Chart with tooltip-backed legend; and (4) Task Completion Velocity Area Chart with subtle gradient fill. It orchestrates these widgets inside `AnalyticsDashboard.tsx` with segmented timeframe tabs, skeleton loaders, error handling, and zero-data empty states, mounted inside `<Shell layoutMode="scroll">` at route `src/routes/tools.analytics.tsx`.

     ```typescript
     const analyticsSearchSchema = z.object({
       range: z.enum(["today", "last7Days", "last30Days", "allTime"]).default("last7Days").catch("last7Days"),
     });
     ```
   - Define route:
     ```typescript
     export const Route = createFileRoute("/tools/analytics")({
       validateSearch: (search) => analyticsSearchSchema.parse(search),
       head: () => ({
         meta: [
           { title: "Analytics Dashboard — AKIRA" },
           { name: "description", content: "Focus session duration trends, task velocity, and project distributions." },
         ],
       }),
       component: AnalyticsPageRoute,
     });

     function AnalyticsPageRoute() {
       const { range } = Route.useSearch();
       const navigate = Route.useNavigate();
       return (
         <Shell layoutMode="scroll">
           <AnalyticsDashboard
             initialRange={range}
             onRangeChange={(newRange) => navigate({ search: { range: newRange } })}
           />
         </Shell>
       );
     }

     export default AnalyticsPageRoute;
     ```
